Libra Prototype

A self-hosted answer engine that shows its work

Five screens of desktop-first product UI. Every claim in an answer carries a numbered chip that lights its entry in the sources rail — on the desktop that rail is always there, on mobile it is a sheet.

  • DirectionEditorial — paper, ink, hairlines. No cards, no shadows on content.
  • Palette
  • TypeCharter / Iowan Old Style for the answer and headlines; system sans for chrome; mono for metadata and citation numbers.
  • ThemeLight-first, dark mode persisted across all screens.

Walking someone through it

A two-minute path

The order that makes the citation model land for someone seeing Libra for the first time.

  1. Open Home and send the Firecracker question as written.
  2. Watch retrieval land before a single word is written — that ordering is the product argument.
  3. On the finished answer, hover chip 3, then filter the rail to Docs.
  4. Switch to dark in Settings, then come back — it followed you.
  5. End on mobile: the rail is the same object, just folded.

What actually works

  • Hover or focus any numbered citation to light its rail entry; click to scroll the rail to it.
  • Filter the rail by Web, Docs, or Code — the count updates with the filter.
  • [ collapses the thread sidebar, / jumps to the composer; both preferences persist.
  • Theme is shared across every screen through localStorage, so dark mode survives navigation.
  • The streaming screen can be stopped mid-answer and replayed.
